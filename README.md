# federicapadovano.github.io

Personal academic website of Federica Padovano: https://federicapadovano.github.io/

Plain HTML + one stylesheet (`style.css`), hosted on GitHub Pages.

- `index.html`, `research.html`, `talks.html` – the three pages (the sidebar is repeated in each: if you change it, change it in all three)
- `FP_CV.pdf` – CV
- `sitemap.xml` – list of pages for Google; update the `lastmod` dates when you change something
- Colours are defined once at the top of `style.css`
